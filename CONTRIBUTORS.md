# Contribuições e autoria — Leitura Digital

Este documento registra as contribuições intelectuais, metodológicas e técnicas relacionadas ao Leitura Digital. Deve ser preenchido de forma fiel ao trabalho efetivamente realizado e mantido coerente com a dissertação, o protocolo de pesquisa e a documentação ética.

## 1. Princípio de atribuição

A autoria do projeto deve distinguir claramente:

- concepção do problema de pesquisa;
- concepção pedagógica;
- metodologia;
- elaboração e refinamento de prompts;
- especificação funcional;
- arquitetura tecnológica;
- programação;
- integração de serviços externos;
- validação pedagógica;
- validação técnica;
- governança dos dados;
- análise formal;
- redação científica;
- manutenção do software.

A expressão “desenvolvimento do Leitura Digital” não deve ser interpretada automaticamente como programação integral pela pesquisadora. A participação de cada pessoa deve ser descrita de forma explícita.

## 2. Referência de contribuição

Este projeto utiliza como referência a taxonomia CRediT, adaptada ao contexto de software de pesquisa.

| Categoria | Aplicação no projeto |
| --- | --- |
| Conceptualization | Definição do problema, objetivos e finalidade do instrumento |
| Methodology | Definição dos procedimentos de pesquisa e uso do sistema |
| Software | Programação, arquitetura e implementação |
| Validation | Testes pedagógicos e técnicos |
| Data Curation | Organização, proteção, retenção e tratamento dos dados |
| Formal Analysis | Definição e análise de métricas e resultados |
| Investigation | Execução dos procedimentos de pesquisa |
| Visualization | Relatórios, gráficos e interfaces analíticas |
| Writing – Original Draft | Redação inicial da dissertação e documentos científicos |
| Writing – Review & Editing | Revisão e edição científica/técnica |
| Supervision | Orientação acadêmica e metodológica |
| Project Administration | Coordenação do projeto |
| Resources | Disponibilização de infraestrutura e recursos |
| Maintenance | Correções, atualizações e sustentação do software |

## 4. Serviços externos

Os seguintes fornecedores podem participar do funcionamento técnico, mas não constituem automaticamente autoria científica:

- OpenAI — processamento por IA na configuração de produção;
- Google/Firebase — autenticação e persistência;
- Vercel — hospedagem e execução;
- frameworks e bibliotecas de código aberto.

Eles devem ser descritos como dependências tecnológicas ou serviços externos.

## 5. Evidências de contribuição técnica

Quando aplicável, a contribuição técnica pode ser rastreada por:

- commits;
- pull requests;
- issues;
- documentação;
- histórico de versões;
- CI;
- releases e snapshots usados na coleta.

## 6. Revisão antes de publicação

Antes de dissertação, artigo ou relatório, verificar:

1. se todas as contribuições estão corretamente atribuídas;
2. se nenhuma participação relevante foi omitida;
3. se serviços externos foram descritos como dependências e não como autores;
4. se a versão do software citada corresponde à versão efetivamente utilizada na pesquisa.
